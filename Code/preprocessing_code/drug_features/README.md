# Drug Features Preprocessing Codes
The codes are for preprocessing the drug features used in this study. If you are interested in reproducibility at the first place, you could use these codes for retriving the drug features used in this study. All proprocessed data are given in the ./Data/FinalData.

## Morgan_Fingerprints
This folder contains the code for preprocessing Morgan Fingerprints. The preprocessed data is called 'compounds_512MFP_wholeDat_fixed.csv' inside the path './Data/FinalData'.

## LLM_derived_Embeddings
This folder contains the code for preprocessing Drug embeddings derived from LLMs. The preprocessed data is called 'gptEmbed_Jul9_final.csv' inside the path './Data/FinalData'.

## Multihot_targets_encoding.
This folder contains the code for preprocessing multi-hot encoded targets information. The preprocessed data is called 'compounds_target_multihot_full.csv' inside the path './Data/FinalData'.
