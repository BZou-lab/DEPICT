# other_models
This folder contains 2 folders, which are "PRNet" and "TranSiGen".

## PRNet
This folder contains codes that train and infer for PRNet: https://www.nature.com/articles/s41467-024-53457-1. The original GitHub page is: https://github.com/Perturbation-Response-Prediction/PRnet. Please clone the whole repository before running my modified code.

## TranSiGen
This folder contains codes that train and infer for TranSiGen: https://www.nature.com/articles/s41467-024-49620-3. The original GitHub page is: https://github.com/myzhengSIMM/TranSiGen. Please clone the whole repository before running my modified code.

## FiveSimpleBaselines
This folder contains 5 simple baseline predictions that we used to benchmark the performance of other frameworks. This is because the observations from Ahlmann-Eltze et al.(https://www.nature.com/articles/s41592-025-02772-6), showed that recent deep learning frameworks perform worse than simple predictions such as using baseline gene expression as the perturbed gene expression.
