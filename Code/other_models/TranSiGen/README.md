# TranSiGen
This folder contains codes and data that train and infer for TranSiGen, used in my study. The original GitHub page for PRNet is: https://github.com/myzhengSIMM/TranSiGen. 

## Important
Please clone the whole git repository from the original TranSiGen study before runing my modified code. The original repository contains many must-have codes to run my modified version. After you cloned the TranSiGen's code, you should have the following 3 folders: 'data', 'results' and 'src'.

## data
All the data used for training and inferring. The data is identical to what is used in DEPICT and PRNet, but in different format to suit for TranSiGen.

## results
All results are stored in this folder.

## src
All the codes used for training and inferring the TranSiGen's performance. My modified codes should also be inside this folder, with other original codes in the TranSiGen.

## preprocessing_codes
This folder contains the codes for cleaning and preprocessing the data that would be used in the TranSiGen.
