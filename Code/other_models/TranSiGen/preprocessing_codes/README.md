# TranSiGen Preprocessing Codes
This folder contains codes for making the identical dataset used in this study to suit for TranSiGen training and inference. The original GitHub page for PRNet is: https://github.com/myzhengSIMM/TranSiGen. 

## CreateFirstH5Data.ipynb
Run this first. Create the main perturbational data for TranSiGen.

## CreateIDX2SMILES.ipynb
Run this second. Create a dictionary that maps ID to SMILES.


## CreateSMI2MFP.ipynb
Run this third. Create the 2048-bit Morgan Fingerprints.


## CreateIDh5data_firstHalf.ipynb and CreateIDh5data_SecondHalf.ipynb
Run this last. Create the ID dictionary for the perturbational data.
