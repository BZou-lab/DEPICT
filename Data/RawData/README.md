# Raw Data
This folder should contain several files:

## Lincs_L1000.h5ad
This file is not uploaded here due to the limit size in GitHub.
This file is a must-to-download if you would like to replicate our study.
We preprocess the LINCS L1000 data starting from this file.

Original file can be downloaded at: https://zenodo.org/records/14230870.

The original file is from another study: "Predicting transcriptional responses to novel chemical perturbations using deep generative model for drug discovery" from Nat Comm 2024.

## Drug list and metadata
Two files named as: "GSE92742_Broad_LINCS_pert_info.txt" and "GSE92742_Broad_LINCS_pert_metrics.txt" are the compound list and metadata for all the compounds.

The original files can be downloaded from the LINCS L1000 NCBI page:https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE92742.

## halfway_data
This is the folder for you to contain any generated data halfway when preprocessing the raw data.
